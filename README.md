# retail-_scales_data
# Retail Sales Analysis — Beginner Data Analyst Project

This project practices the basic skills used by a data analyst:

- Loading a CSV file
- Checking and cleaning data
- Calculating summary statistics
- Grouping data by category and region
- Finding top products
- Creating simple charts
- Writing business conclusions

## Tools

- Python
- pandas
- matplotlib

## Run the project

```bash
pip install -r requirements.txt
python analysis.py
```

The script prints key findings and saves charts in the `charts` folder.

## Questions answered

1. What is the total revenue?
2. Which product category performs best?
3. Which region generates the most revenue?
4. Which products sell the most units?
5. How does revenue change over time?
